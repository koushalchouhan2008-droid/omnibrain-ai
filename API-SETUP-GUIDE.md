# AI and external API configuration
Connections Marketplace provides built-in model cards for OpenAI, Anthropic, Gemini, DeepSeek, Groq, xAI (Grok), Mistral, OpenRouter, Hugging Face, Together, Perplexity, Ollama, Brave and Tavily. Create a developer account directly with your desired provider, generate a key, check billing/quotas and copy it into the app's server-backed credential form. Models are editable; defaults may retire. Test each connection before use. Use provider official documentation and don't send credentials via URL parameters.

Custom AI: provide full HTTPS OpenAI-compatible chat completions endpoint and model name plus bearer key if needed. Public HTTPS URL: research content or bookmark; not automatic authenticated browsing. REST tool: read-only GET, optional bearer authentication. Search tool: public endpoint returning JSON results. The connector catalog is extensible through these supported contracts; MCP/OpenAPI import and arbitrary methods/custom headers are not implemented.

Free Mode chooses configured OpenRouter models ending `:free` or locally enabled Ollama; quota still applies. For Ollama run it on the same server host on loopback port 11434, set `OLLAMA_ENABLED=true`, pull the model with `ollama pull llama3.2`, and configure it in app. Do not expose Ollama publicly. Other modes can incur charges; no hard monetary budget enforcement exists. Configure limits in provider dashboards. Usage records provider-reported tokens and request status, not inferred dollar costs.

Image generation requires OpenAI image API and video requires xAI video API (select actual enabled model). Jobs may fail if billing, model or account entitlement is missing. No media is fabricated. GitHub: create a fine-grained token with only the necessary read access, save it under marketplace GitHub and test/read repositories. Revoke on GitHub to remove remote permissions. Other services need a supported custom API contract or future adapter.
