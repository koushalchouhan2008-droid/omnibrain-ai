# Local installation (Hindi/Hinglish)
1. ZIP extract karo; folder ke andar package.json hona chahiye.
2. https://nodejs.org se Node.js 22.13 ya newer install karo. Terminal mein `node -v` check karo.
3. Terminal/CMD mein project folder open karo. `npm start` chalao. Koi dependency install zaroori nahi.
4. Browser mein http://localhost:3000 kholo. Create account par apni app ka email aur naya 12-character password banao; Google ka password kabhi mat dalo.
5. Connections Marketplace mein supported AI ka API key aur model set karo, Test karo. Free mode ke liye OpenRouter :free model ya enabled local Ollama use karo.
6. Knowledge, Agents, Automation, Image/Video Studio, Builder aur Artifacts sidebar se kholo. Providers ke credentials ke bina generation nahi chalegi.
7. `Ctrl+C` se server band. Server band hone par scheduled automation bhi rukti hai. `data/` ka encrypted key, database aur media ka secure backup lo; GitHub par upload mat karo.
8. Windows/macOS/Linux: terminal method recommended. Android par browser se deployed URL kholo; phone par HTML offline preview dekh sakte ho, server alag machine par chalega.
9. Test: `npm run check`. Port busy ho to .env mein PORT change karo aur browser URL update karo. Production ke liye Netlify guide follow karo.
